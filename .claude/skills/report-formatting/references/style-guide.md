# Report Style Guide

## Prose Standards

### Clarity
- One idea per paragraph. If a paragraph covers two ideas, split it.
- Lead each paragraph with the main point, then support it.
- Use active voice by default. Passive voice only when the actor is unknown or irrelevant.
- Prefer short sentences (15-25 words). Mix in occasional longer ones for rhythm.

### Precision
- Use specific numbers: "grew 34% year-over-year" not "grew significantly."
- Name sources inline: "According to the Bureau of Labor Statistics" not "according to data."
- Include time frames: "in Q3 2025" not "recently."
- Specify geography when relevant: "in the EU market" not "globally" unless it is global.

### Tone
- Professional but readable. Not academic, not casual.
- Confident where evidence is strong. Hedged where it's weak.
- Never use: "It's important to note that", "It should be noted", "Interestingly", "In conclusion."
- Avoid filler phrases: "In order to" → "To"; "Due to the fact that" → "Because"; "At this point in time" → "Now."

## Structure Rules

### Headings
- Use descriptive headings: "AI Spending Surged in 2025" not "Market Overview"
- Maintain strict hierarchy: H1 > H2 > H3. Never skip levels.
- No heading should appear without at least one paragraph of text beneath it.

### Paragraphs
- Minimum 2 sentences. Maximum ~6 sentences.
- No single-sentence paragraphs except in the executive summary.
- Transition between paragraphs. Each should connect to the next logically.

### Citations
- Inline format: (Source Name, Date)
- Place citations at the end of the sentence they support, before the period.
- If multiple sources support the same claim, combine: (Source A, 2025; Source B, 2025)
- If a source is used repeatedly in one section, name it fully on first use, then abbreviate.

### Data Presentation
- When comparing numbers, use consistent units and time frames.
- Round appropriately: $4.2 billion, not $4,217,839,201.
- When a number is surprising, add context: "a 34% increase — the largest since 2019."
- Present data in the text as prose. Use tables only if comparing 3+ items across 3+ dimensions, and only when explicitly helpful.

## What Not to Do

- Never start a report with a dictionary definition.
- Never use bullet-point lists in the findings or analysis sections.
- Never write "This report will explore..." — just explore it.
- Never pad with obvious statements: "AI is a rapidly growing field."
- Never end with "Only time will tell" or similar non-conclusions.
- Never use the phrase "It is worth noting" — if it's worth noting, just note it.
