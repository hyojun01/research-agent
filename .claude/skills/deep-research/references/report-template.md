# Report Templates

## Brief Report (500-1,000 words)

Use for simple factual questions or narrow topics.

```
# {Title}

**Date:** {date} | **Confidence:** {level}

## Summary

{3-5 sentences covering the key finding and its implications.}

## Key Findings

{2-3 paragraphs of prose. No bullet points.}

## Sources

{Numbered list, 3-8 sources}
```

## Standard Report (1,500-3,000 words)

Use for typical research requests.

```
# {Title}

**Date:** {date} | **Confidence:** {level}

---

## Executive Summary

{2-4 sentences.}

## Background

{1-2 paragraphs of context.}

## Findings

### {Section 1}
{Prose paragraphs with inline citations.}

### {Section 2}
{Continue as needed. Typically 2-4 sections.}

## Analysis

{Cross-cutting insights, 1-2 paragraphs.}

## Limitations

{1 paragraph on what's missing or uncertain.}

## Sources

{Numbered list, 8-20 sources}
```

## Deep Report (3,000-6,000 words)

Use for comprehensive, multi-faceted research.

```
# {Title}

**Date:** {date} | **Confidence:** {level}

---

## Executive Summary

{4-6 sentences. Include the single most important number or fact.}

## Background

{2-3 paragraphs establishing context and why this matters now.}

## Methodology

{Brief note on how research was conducted, scope, and time frame of sources.}

## Findings

### {Major Section 1}

#### {Subsection 1a}
{Detailed prose.}

#### {Subsection 1b}
{Detailed prose.}

### {Major Section 2}
{Continue. Typically 3-6 major sections.}

## Analysis & Implications

{What the findings mean when taken together. 2-4 paragraphs.}

## Competing Perspectives

{Where experts or sources disagree, presented fairly.}

## Limitations & Further Research

{What this report doesn't cover. Suggestions for deeper investigation.}

## Sources

{Numbered list, 15-40 sources}
```

## Citation Style

Inline: (Source Name, Date)
Bibliography entry: {N}. {Author/Org}. "{Title}." {Publication}, {Date}. {URL}

If no author: use organization name.
If no title: use a descriptive phrase in brackets.
If no date: write "n.d."
