# Citation Standards

These rules apply to all files in `output/` and `sources/`.

## Mandatory

- Every factual claim requires an inline citation: (Source Name, Date)
- Every cited source must appear in the Sources section with a full URL
- Never fabricate or hallucinate a source. If you cannot find a source, state the claim is unverified.
- Never invent a URL. Every URL must come from an actual search result or web fetch.

## Quoting

- Paraphrase by default. Rewrite in your own words.
- Direct quotes: only when exact wording has legal, definitional, or rhetorical significance.
- All direct quotes must be under 15 words.
- Maximum one direct quote per source across the entire report.
- Never string together multiple small quotes from the same source.

## Source Format

Bibliography entry format:
```
{N}. {Author or Organization}. "{Title}." {Publication}, {Date}. {URL}
```

If no author: use organization name.
If no publication: use domain name.
If no date: write "n.d."
If title is unavailable: use a descriptive bracket phrase like [Press release on Q3 earnings].
